## 一、資料庫 Schema

### 1.1 `sms_templates`（簡訊模板）

| 欄位 | 型別 | 說明 |
|---|---|---|
| `id` | VARCHAR(36) PK | UUID，系統內建以 `builtin_` 前綴 |
| `store_id` | INT FK | NULL = 全系統共用，非 NULL = 門市自訂 |
| `name` | VARCHAR(64) NOT NULL | 模板名稱，同門市範圍內唯一 |
| `desc` | VARCHAR(128) | 用途說明 |
| `body` | TEXT NOT NULL | 模板內容，含 `{{參數}}` token |
| `scenario` | VARCHAR(32) | 用途分類，預設 `預約簡訊` |
| `creator_id` | INT FK | 建立者帳號 ID，NULL = 系統預設 |
| `created_at` | DATETIME | 建立時間 |
| `updated_at` | DATETIME | 最後修改時間 |
| `enabled` | BOOLEAN | 停用不出現在預約頁下拉 |
| `is_builtin` | BOOLEAN | true = 不可刪除 |

**索引**：`(store_id, enabled, scenario)`

---

### 1.2 `sms_user_preferences`（個人偏好）

| 欄位 | 型別 | 說明 |
|---|---|---|
| `user_id` | INT PK FK | |
| `pinned_ids` | JSON | 釘選模板 ID 陣列 |
| `recent_ids` | JSON | 最近使用模板 ID 陣列（上限 5） |
| `last_used_id` | VARCHAR(36) | 上次套用的模板 ID |
| `updated_at` | DATETIME | |

---

### 1.3 `sms_store_settings`（門市簡訊設定）

| 欄位 | 型別 | 說明 |
|---|---|---|
| `store_id` | INT PK FK | |
| `sms_enabled` | BOOLEAN | 全域發送開關 |
| `include_tele` | BOOLEAN | 包含電訪推廣附加語 |
| `updated_at` | DATETIME | |

---

### 1.4 `sms_send_log`（發送記錄）

| 欄位 | 型別 | 說明 |
|---|---|---|
| `id` | BIGINT PK AUTO | |
| `appointment_id` | INT FK | 對應預約 ID |
| `template_id` | VARCHAR(36) FK | 套用的模板 ID（快照用） |
| `recipient_masked` | VARCHAR(20) | 手機末四碼隱碼，如 `09xx-ooo-1234` |
| `content` | TEXT | 實際發送的簡訊文字（已解析參數） |
| `char_count` | INT | 字數 |
| `segments` | INT | 簡訊則數 |
| `scheduled_at` | DATETIME | 預計發送時間（NULL = 立即） |
| `sent_at` | DATETIME | 實際送出時間 |
| `status` | ENUM | `pending` / `sent` / `failed` |
| `gateway_ref` | VARCHAR(128) | 電信商回傳的訊息 ID |
| `error_msg` | VARCHAR(256) | 失敗原因 |
| `created_at` | DATETIME | |

> `recipient_masked` 儲存隱碼版本；完整手機號碼由預約資料的 `member_id` 關聯取得，不直接儲存於此表。

## 二、API 端點

### 2.1 模板管理

#### `GET /api/sms-templates`

取得可用模板清單（含全系統共用 + 當前門市自訂）。

**Query Params**

| 參數 | 說明 |
|---|---|
| `store_id` | 必填；自動帶入 session 所屬門市 |
| `scenario` | 選填，預設 `預約簡訊` |
| `enabled_only` | `true`（預約頁下拉）/ `false`（設定頁全覽） |

**Response 200**

```json
{
  "templates": [
    {
      "id": "builtin_std",
      "name": "標準預約提醒",
      "desc": "適用一般預約",
      "body": "親愛的{{會員姓名}}您好...",
      "creator": null,
      "created_at": "2026-01-01T00:00:00Z",
      "enabled": true,
      "is_builtin": true,
      "scenario": "預約簡訊"
    }
  ]
}
```

---

#### `POST /api/sms-templates`

新增自訂模板。

**Request Body**

```json
{
  "store_id": 5,
  "name": "中醫午診提醒",
  "desc": "適用午診預約",
  "body": "親愛的{{會員姓名}}您好，提醒您預約{{門市名稱}}，{{預約日期}} {{預約時間}}。",
  "scenario": "預約簡訊",
  "enabled": true
}
```

**Response 201**：回傳建立後的完整模板物件（含 `id`、`created_at`）

**Validation**

- `name` 不可空、同門市不重複
- `body` 不可空，長度上限 500 字元
- `body` 只允許白名單參數 token（見第三節）

---

#### `PUT /api/sms-templates/:id`

更新模板（含停用 / 啟用）。系統內建模板僅允許更新 `enabled` 欄位。

**Response 200**：回傳更新後物件

**Error 403**：嘗試修改系統內建模板的 `name` / `body`

---

#### `DELETE /api/sms-templates/:id`

刪除自訂模板。

**Error 400**：`is_builtin = true`，不允許刪除

### 2.3 簡訊發送

#### `POST /api/sms/send`

**Request Body**

```json
{
  "appointment_id": 10042,
  "template_id": "builtin_std",
  "content": "親愛的王小明您好，提醒您已預約三重麗雅，日期：07/03（五） 14:00，療程：深層清潔，地點：三重區正義北路122號，來電：02-29850300。",
  "scheduled_at": "2026-07-03T08:00:00+08:00"
}
```

| 欄位 | 說明 |
|---|---|
| `appointment_id` | 後端從此取得會員手機號碼（不由前端傳入） |
| `template_id` | 僅用於記錄，非再次解析用 |
| `content` | 前端已解析的最終文字（人員可能已手動修改） |
| `scheduled_at` | NULL 或省略 = 立即發送 |

**後端行為**

1. 從 `appointment_id` 取得會員手機（確認會員「不拒絕簡訊」；否則 400）
2. 驗證 `content` 長度 ≤ 670 字
3. 寫入 `sms_send_log`（recipient_masked、content、segments）
4. 若 `scheduled_at` 為未來時間 → 寫入排程佇列（`status = pending`）
5. 若立即發送 → 呼叫 SMS Gateway API，更新 `status`、`sent_at`、`gateway_ref`

**Response 200**

```json
{
  "log_id": 9981,
  "status": "sent",
  "scheduled_at": null,
  "segments": 2
}
```

**Error Cases**

| HTTP | 情境 |
|---|---|
| 400 | 會員設定拒絕簡訊 |
| 400 | content 超過 670 字 |
| 404 | appointment_id 不存在 |
| 503 | SMS Gateway 回傳失敗 |

## 三、參數白名單

`body` 欄位只允許以下 token，其他 `{{...}}` 格式在儲存時回傳 400。

| Token | 解析來源 |
|---|---|
| `{{會員姓名}}` | `appointments.member_name` |
| `{{門市名稱}}` | `stores.name` |
| `{{預約日期}}` | `appointments.date`（格式化 MM/DD（星期））|
| `{{預約時間}}` | `appointments.time`（HH:MM）|
| `{{療程}}` | `appointments.treatment_name` |
| `{{門市地址}}` | `stores.address` |
| `{{門市電話}}` | `stores.phone` |

## 四、SMS Gateway 整合

### 4.1 介接規格（參考，依實際電信商調整）

| 項目 | 說明 |
|---|---|
| 協定 | HTTPS REST |
| 認證 | Bearer Token（後端環境變數管理，不暴露給前端） |
| 送出 endpoint | `POST https://sms-gateway.example/send` |
| 重試策略 | 失敗後 3 次重試，間隔 30s / 60s / 120s |
| 失敗通知 | 寫入 `sms_send_log.error_msg`；超過重試上限則通知運維 |

### 4.2 手機號碼處理

- 完整手機號碼僅於發送當下由後端記憶體中取用，不記錄於 Log。
- Log 儲存隱碼格式：`09xx-ooo-NNNN`（僅保留末四碼）。
- API Request/Response 不包含完整手機號碼。
